# Skill "Feriados ContaPrazo"

Ensina o Claude (app ou site claude.ai) a transformar um decreto, portaria ou provimento no arquivo de conjunto de feriados do ContaPrazo, seguindo os padrões do projeto.

## Instalar

1. Compacte esta pasta em um `.zip` (a pasta `skill-feriados-contaprazo` com o `SKILL.md` dentro).
2. No Claude: **Configurações → Capacidades → Skills → Enviar skill** e escolha o `.zip`.

## Usar

Numa conversa qualquer, envie o PDF ou o link do ato normativo e diga qual conjunto atualizar (ex.: "atualiza o TJBA com este decreto"). O Claude mostra a lista de datas para você conferir e devolve o arquivo pronto, com as instruções para publicar no GitHub.
